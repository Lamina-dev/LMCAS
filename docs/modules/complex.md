# 说明

### 复数四则运算
- 重载运算符，支持 double、Rational、BigInt。
- 算法：按复数实部/虚部分别运算。
- 特性：支持符号混合。
- 局限：复数轨迹、复方程求根未完善。

### 极坐标/指数形式
- 支持 to_complex()、to_double() 转换。
- 算法：模长与角度转换，指数形式 e^(iθ)。
- 特性：支持符号角度。
- 局限：高阶复数变换未支持。

### to_symbolic()
- 转换为符号表达式。
- 算法：构造 SymbolicExpr 节点。
- 特性：支持符号化简。
- 局限：复杂嵌套下效率低。

### to_double()
- 数值化。
- 算法：实部/虚部转 double。
- 特性：支持高精度。
- 局限：精度损失。

### to_string()
- 格式化输出。
- 算法：按实部/虚部格式化字符串。
- 特性：支持符号输出。
- 局限：复杂嵌套下格式化有限。
# 复数模块

主要头文件：`include/irrational.hpp`、`include/value.hpp`

## Irrational

- 复数/无理数类型，支持模长、共轭、极坐标转换。
- 算法：
	- 四则运算：重载运算符，支持 double、Rational、BigInt。
	- 极坐标/指数形式：to_complex()、to_double() 支持转换。
- 特性：
	- 支持复数表达式与符号化简。
	- 支持复数与符号混合运算。
- 已知问题：
	- 复数轨迹、复方程求根未完善。

## 主要函数

- `to_symbolic()`：转换为符号表达式。
- `to_double()`：数值化。
- `to_string()`：格式化输出。
