# 说明

### integrate(expr, var)
- 积分主入口，自动选择分部积分、换元、部分分式分解等策略。
- 算法：递归遍历表达式树，优先检测乘积结构（分部积分）、可换元结构（换元法）、有理函数（部分分式）。
- 特性：自动防止递归爆炸，支持积分历史。
- 局限：高阶积分、特殊函数积分未支持。

### 分部积分（Integration by Parts, IBP）
- 自动识别乘积结构，优先积分易积分部分。
- 算法：分解为 u*v，递归积分 v，微分 u。
- 特性：支持多层嵌套。
- 局限：复杂嵌套时易爆炸。

### 换元法（Substitution）
- 自动检测可换元表达式，构造新变量。
- 算法：识别 f(g(x)) 结构，令 t=g(x)，递归积分。
- 特性：支持嵌套换元。
- 局限：复杂嵌套下变量绑定难度大。

### 部分分式分解（Partial Fraction）
- 对有理函数自动分解。
- 算法：分解分母为因式，拆分为简单分式，递归积分。
- 特性：支持高阶有理函数。
- 局限：分母不可因式分解时无解。

### IntegralHistory
- 积分历史记录，防止递归死循环。
- 算法：每次积分前记录表达式，遇到重复则终止。
- 特性：自动防止死循环。
- 局限：历史表过大时性能下降。

### DifferentiationVisitor
- 微分访问者，递归遍历表达式树，自动识别参数方程。
- 算法：链式法则、乘法法则、幂法则。
- 特性：支持显式函数、参数方程。
- 局限：隐函数微分、分段函数未支持。

### series(var, point, order)
- 泰勒/麦克劳林级数展开，递归求导并构造多项式。
- 算法：自动化高阶导数，按阶累加构造多项式。
- 特性：支持符号系数，自动化简。
- 局限：高阶导数性能瓶颈，分段函数未支持。
# 微积分模块

主要头文件：`include/integration.hpp`、`include/visitors/differentiation_visitor.hpp`

## Integrator

- 积分器类，主入口 `integrate(expr, var)`。
- 算法：
	- 分部积分（IBP）：自动识别乘积结构，优先积分易积分部分。
	- 换元法（Substitution）：自动检测可换元表达式，构造新变量。
	- 部分分式分解（Partial Fraction）：对有理函数自动分解。
	- 启发式策略：根据表达式结构优先选择算法，防止递归爆炸（IntegralHistory）。
- 特性：
	- 支持积分历史，防止死循环。
	- 自动检测奇点与不可积结构。
- 已知问题：
	- 不支持高阶积分、特殊函数积分，Risch 算法未实现。

## DifferentiationVisitor

- 微分访问者，支持链式法则、乘法法则、幂法则。
- 算法：递归遍历表达式树，自动识别参数方程。
- 特性：
	- 支持显式函数、参数方程。
- 已知问题：
	- 隐函数微分、分段函数未支持。

## 级数展开

- `series(var, point, order)`：递归求导，构造泰勒/麦克劳林多项式。
- 算法：自动化高阶导数，支持符号系数。
