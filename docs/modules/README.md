# 模块总览

LMCAS 按功能划分为多个模块：

- [symbolic.md](symbolic.md)：符号表达式与基础运算
	- AST结构、节点类型、模式匹配、化简、展开、规范化
- [calculus.md](calculus.md)：微积分模块
	- 积分器、微分访问者、级数展开、算法与特性
- [algebra.md](algebra.md)：代数与方程模块
	- 多项式、因式分解、方程求解、算法与特性
- [matrix.md](matrix.md)：矩阵与向量模块
	- 矩阵运算、线性变换、特征值/向量、算法与特性
- [complex.md](complex.md)：复数模块
	- 复数类型、极坐标、符号化简、算法与特性
- [utils.md](utils.md)：工具与辅助模块
	- Value类型、模块、函数、辅助特性、已知问题

各模块详细说明见对应文档。
