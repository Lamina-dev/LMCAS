# 说明

### 多项式加减乘除
- 传统多项式算法，按项合并、递归处理系数。
- 算法：遍历项列表，按指数合并同类项。
- 特性：支持高精度系数、符号系数。
- 局限：多元多项式支持有限。

### div_mod、pseudo_div_mod
- 多项式除法，返回商和余数。
- 算法：递归减去最高项，直到余数次数低于除数。
- 特性：支持符号系数。
- 局限：符号系数下除法复杂度高。

### GCD（最大公约数）
- 欧几里得算法，递归调用除法，直到余数为零。
- 算法：多项式除法，返回最后非零多项式。
- 特性：支持高精度、符号多项式。
- 局限：多元多项式支持有限。

### 因式分解
- 递归分解，支持部分分式。
- 算法：尝试分解为低阶因式，递归处理。
- 特性：支持符号系数。
- 局限：高阶多项式分解效率低。

### 高斯消元
- 方程组求解，构造增广矩阵，逐步消元，回代求解。
- 算法：逐行消元，回代求解。
- 特性：支持符号系数。
- 局限：非线性方程组未支持。

### 符号化解
- 自动识别变量，支持符号化解。
- 算法：提取变量，构造符号表达式。
- 特性：支持多变量。
- 局限：复杂嵌套下变量提取难度大。
# 代数与方程模块

主要头文件：`include/polynomial.hpp`、`include/poly_utils.hpp`、`include/solver.hpp`

## Polynomial<T>

- 多项式模板类，支持高精度整数、有理数、符号系数。
- 算法：
	- 加减乘除：传统多项式算法。
	- 除法：多项式除法，支持 div_mod、pseudo_div_mod。
	- GCD：欧几里得算法。
	- 因式分解：递归分解，支持部分分式。
- 特性：
	- 支持多元多项式（有限），符号系数。
- 已知问题：
	- 多元多项式支持有限，Groebner 基未实现。

## Solver

- 方程求解器，支持线性方程组。
- 算法：
	- 高斯消元法，构造增广矩阵，逐步消元，回代求解。
	- 支持符号系数。
- 特性：
	- 自动识别变量，支持符号化解。
- 已知问题：
	- 非线性方程组、微分方程未支持。
